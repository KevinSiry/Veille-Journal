# Veille Journal

Journal de veille personnel : chaque nuit, un worker collecte les actualités de vos thèmes
(flux RSS + SearXNG), les filtre, les résume en français avec un modèle local (Ollama) et
publie un article très court par thème et par jour, avec les sources citées.

Documentation complète à venir (démarrage local, déploiement) dans `docs/SETUP.md`.
